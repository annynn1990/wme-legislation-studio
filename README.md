# 黃名帝國國會修法助手（WME Legislative Assistant）

本專案的主要使用者是國會議員，核心工作不是管理法律檔案，而是協助議員針對既有法律提出修正。

## 議員使用流程

1. 從法規庫選擇需要修改的法律。
2. 選擇修改現有條文、增訂條文或刪除條文。
3. 用一般語言描述現行法律遇到的問題及希望達成的效果。
4. 對照現行條文，編輯修正後文字及修正理由。
5. 將一項或多項修改整理成修正草案，複製或下載，供議會審議。

## 法規資料

- 正式法律資料位於 \`site/data/laws.json\`。
- 每條條文保留法規名稱、章節、條號、原文及來源資訊。
- 法律狀態不明時應標示為待核實，不可將未知效力當成現行法。
- 草案只是一份提案文件，不會直接取代或修改已公布法律。修法通過並正式公布後，管理者才更新正式法規資料。

## 現階段功能

- 法律及條文查閱。
- 修正既有條文、增訂條文、刪除條文。
- 現行文字與修正文字對照。
- 修正理由整理。
- 將多項修改輸出為修法草案，支援複製及下載。

目前 GitHub Pages 版本提供前端修正工作台及草案格式整理。AI 跨法規衝突分析、法案建議及自動草擬尚未接入模型 API；介面不會把關鍵字檢索或人工編輯假稱為 AI 法律分析。

## 部署

網站為 GitHub Pages 靜態前端，法律資料以 JSON 儲存在同一個 Repository。每次更新 \`site/**\` 後，GitHub Actions 會自動部署。
